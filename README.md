# Dayfront — clickable prototype

A static, clickable prototype of the Dayfront clinic app: 17 screens in the Graphite pro design, light and dark.
Open the site and start at sign-in ("Continue with passkey"); press **H** to outline what is clickable, and use
the **Screens** menu to jump anywhere. Buttons that would change data show a note explaining what the real app does.

**All data is fictional** (Lakeview Dental Care and every patient and staff name are invented). This is not the
product and holds no real information. Built from the mockups in the private `dayfront/dayfront` repository.
